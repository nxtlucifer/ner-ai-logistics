# Redesign image attribution

Every photograph in the redesign comes from Wikimedia Commons under an open licence that was read from the file page (Commons API `extmetadata`) before download. No mockup image, stock-site image or search-engine image is shipped. Originals are kept out of the repo in `.runtime/redesign/sources/` with `metadata.json`; the shipped files are cropped, resized and re-encoded WebP, plus an AVIF of every manager WebP (same crop, same width; since 28 Sep 2026, PERF-3), produced by `.runtime/redesign/optimize_assets.py`.

Downloaded 2026-09-27 (UTC). Changes made to every shipped file: cropped, resized and re-encoded as WebP (manager files also as AVIF); in the product a dark or light scrim is drawn over the photo (CSS/RN overlay, not baked into the file).

**Share-alike.** Files adapted from CC BY-SA sources are released under their source's licence: CC BY-SA 4.0 for the Cherrapunji and Mawkdok files, CC BY-SA 2.0 for the Khasi Hills truck files (the adapted image files only; the application code is not affected by a photo's licence).

**Visible credit in the product (since 1 Oct 2026, company-showcase add-on).** No photo carries a credit control or credit text any more. Every photo is credited in one place per app, with author, licence, licence link and source page:

- **Driver:** More → **Legal & attributions** (the sheet is titled "Attributions").
- **Manager:** account menu → **Legal & attributions** (the dialog is titled "Attributions").

Both lists also restate the map data source: "© OpenStreetMap contributors (ODbL)". The maps keep their own attribution control (Leaflet on the driver map, MapLibre's compact control on the manager maps), and the selected-truck card on the full-screen Fleet map is placed so that it never covers it.

**Why this still complies.** CC BY 2.0/4.0 and CC BY-SA 2.0/4.0 allow attribution "in any reasonable manner based on the medium". For an app, a credits page reachable from the main menu is a reasonable manner. The licence links, the "adapted" notice (cropped, resized, re-encoded, scrim) and the share-alike statement above are unchanged. Removed: the per-photo (i) controls and the driver Login/Navigate/Safety photo credit buttons. Kept: this ledger, `imageCredits.ts` / `photoCredits.ts` metadata, and the tests that tie each shipped file to its credit.

*Before 1 Oct 2026:* each photo carried a small (i) Photo credits control that opened the same list. The 28 Sep table below records that earlier state.
